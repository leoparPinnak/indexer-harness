# Agent Note: Web 客户端中的计划状态：Plan 标签页、模型提议与意图卡片

Status: implemented

[English](2026-09-11-plan-surfaces-in-the-web-client.md) | 中文

## Problem

计划模式只有一条入口——`/plan` 命令——而且事后几乎无从查看。已呈现的计划只能通过产生它的那一轮的审阅卡片、以及标签页唯一的当前面板触达，因此读者既看不到一个会话产生过多少计划，也无法回到较早的那一份。当某个请求确实值得先规划时，模型也无从征询。

唯一存在的提议用英文选项标签提问，而 Web 客户端原样渲染它们，于是使用另一种语言的读者若不翻译提问方的措辞就无法操作这张卡片。对该提议的书面回复还会被丢弃，使提议被读成拒绝，并丢掉用户真正写下的话。

## Decision

**历史是一次折叠，而不是第二个存储。** `plan-mode` 把每一份已呈现的计划折入 `PlanProjection.presented`，按最早在前、上限五十条；视图把最新的那份作为 `presented` 返回，同时给出最新在前的 `history`；由于状态形状改变，该投影的 `stateVersion` 升到 5。Plan 标签页新增当前与历史两个面板：历史面板带数量徽标，每份计划一行标题与日期；当前面板带一个退出计划模式的应用操作；标签页在最新呈现尚未查看时显示标记。

**模型可以提议先做计划。** `enter_plan_mode` 让运行中的 agent 在实施前询问是否先规划，并把理由作为问题 detail 带上。该工具只在计划模式之外可用，被接受的提议经由服务进入计划模式，因此打开的轮次会像 `/plan` 一样把切换排入队列。若回复以自由文本到达，那不算拒绝：它会以用户自己的话抵达模型，因为“让我来说”的路径是卡片上的关闭动作。

**问题意图渲染自己的文案。** 请求可以声明 `plan-review` 或 `plan-offer`；Web 客户端把它收窄到该意图并渲染决定卡片，其条带与动词来自本包自己的语言字典，而回答仍原样使用提问方的选项标签，因此线上编码从不改变。审阅卡片保留提问方的选项描述作为提示，提议卡片则不保留：那些描述是用提问方书写提示词的语言写成的，而卡片是由读者用自己的语言阅读的。既未声明意图、或声明了本构建不认识的意图的请求，仍走通用提问流程。

**待处理的提议会被分类。** Session 行在 `approval`、`plan-review`、`question` 之外点名 `plan-offer`，因此侧边栏会说明等待中的会话在等什么。

## Alternatives considered

**让提议继续走通用提问流程。** 已否决：通用流程用提问方自己的文本标注按钮，而这正是提议对使用另一种语言的读者不可用的原因。

**把较早的计划显示在审阅卡片所属的那一轮里。** 已否决：那张卡片属于呈现该计划的那一轮，而较早的计划比它活得更久——这正是标签页要跟踪历史的原因。

**在客户端翻译提问方的选项标签。** 已否决：标签就是答案的编码，必须原样通过线上传递；而文案自有规则要求产品文本放在字典里，而不是放进去翻译的数据里。

**把书面回复当作拒绝。** 已否决：那会丢掉用户的话，并报告一个他们并未做出的决定。

**保留每一份已呈现的计划。** 已否决：一个会话可能连续数小时呈现计划，而该投影由它所折叠的日志重建；视图最多持有最新的五十份。

## Consequences

- 会话存续期间，每呈现一份计划，`PlanProjection` 就累积一条记录；上限约束的是视图，而不是折叠本身。
- 未知或不可渲染的意图不付出任何代价：通用流程让该请求保持可回答，而这正是客户端位于线上边界下游所要求的。
- 提议卡片的无障碍名称是提问方的问题文本，因此辅助技术读到的是模型的措辞，尽管可见文案是读者自己的语言。
- `enter_plan_mode` 会出现在工具目录以及每一个挂载计划模式的组合中。

## Testing

`packages/plan/plan-mode/tests/projection.spec.ts` 钉住历史折叠，包括其上限与最新在前的顺序；`plan-mode.spec.ts` 钉住该提议的各项行为——接受与拒绝路径、自由文本抵达模型、仅限计划模式之外的约束，以及汇编目录列出该工具。`packages/client/ui-user-questions/tests/plan-presentations.client.spec.tsx` 钉住两种收窄与两张卡片，包括一张用提问方标签作答的土耳其语提议卡片。`packages/client/ui-workspace/tests/tree.client.spec.ts` 与 `rows.client.spec.tsx` 钉住 `plan-offer` 分类及其行标签。
